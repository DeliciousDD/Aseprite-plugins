# Alpha 不透明

在 Aseprite 中，对当前选中的普通图层（该图层的所有帧）执行此命令：

- Alpha 为 `0` 的像素保持完全透明；
- Alpha 为 `1` 到 `254` 的像素改为 `255`（完全不透明）；
- 原有 RGB 或灰度颜色值保持不变；
- 不改变图层不透明度或 Cel 不透明度。

## 使用方式

安装 `pixel-alpha-opaque.aseprite-extension` 后，重启 Aseprite（如需要），打开：

`文件 → 脚本 → Alpha 不透明`

可通过 `编辑 → 键盘快捷键` 为该命令绑定快捷键。

## 限制

仅支持 RGB/RGBA 和灰度/灰度 Alpha 精灵。索引色模式的透明度由调色板共享管理；为避免意外改变同一调色板颜色在其他像素中的表现，插件会提示你先转换颜色模式。

## 开发安装

也可把整个 `pixel-alpha-opaque` 文件夹放在 Aseprite 的扩展目录中，或通过 `编辑 → 首选项 → 扩展 → 添加扩展` 选择发行包。
